# 数据库连接配置

## 📋 连接字符串说明

Supabase 提供两种数据库连接方式：

### 1. 连接池连接 (Connection Pooling) - DATABASE_URL
**用途**：用于应用连接数据库（推荐用于生产环境）
- 端口：`6543`（使用 PgBouncer 连接池）
- 优势：支持大量并发连接，性能更好
- 适用：应用运行时连接

### 2. 直连连接 (Direct Connection) - DIRECT_URL
**用途**：用于数据库迁移和直接数据库操作
- 端口：`5432`（直接连接 PostgreSQL）
- 优势：支持所有 PostgreSQL 功能（如事务、会话变量等）
- 适用：数据库迁移、schema 变更、管理员操作

---

## 🔧 配置方式

### 选项 1: 环境变量（推荐）

#### 如果后端需要直接连接数据库

在 `backend/.env` 文件中添加：

```env
# Supabase 数据库连接（如果后端需要直接连接）
# 注意：替换 [YOUR-PASSWORD] 为你的实际密码

# 连接池连接（用于应用连接）
DATABASE_URL="postgresql://postgres.ebidxktbasohjqfqxxwh:[YOUR-PASSWORD]@aws-0-us-west-2.pooler.supabase.com:6543/postgres?pgbouncer=true"

# 直连连接（用于迁移）
DIRECT_URL="postgresql://postgres.ebidxktbasohjqfqxxwh:[YOUR-PASSWORD]@aws-0-us-west-2.pooler.supabase.com:5432/postgres"
```

#### 前端配置（通常不需要这些连接字符串）

前端使用 Supabase JS 客户端，只需要：

```env
# frontend/.env
VITE_SUPABASE_URL=https://ebidxktbasohjqfqxxwh.supabase.co
VITE_SUPABASE_ANON_KEY=your_anon_key
```

**注意**：前端通过 REST API 连接，不需要 PostgreSQL 连接字符串。

---

### 选项 2: 用于数据库迁移工具

如果你使用数据库迁移工具（如 Prisma、Drizzle、Kysely 等），需要配置这些连接字符串。

#### 示例：Prisma 配置

在 `prisma/schema.prisma` 或 `prisma/.env` 中：

```env
DATABASE_URL="postgresql://postgres.ebidxktbasohjqfqxxwh:[YOUR-PASSWORD]@aws-0-us-west-2.pooler.supabase.com:6543/postgres?pgbouncer=true"
DIRECT_URL="postgresql://postgres.ebidxktbasohjqfqxxwh:[YOUR-PASSWORD]@aws-0-us-west-2.pooler.supabase.com:5432/postgres"
```

#### 示例：Drizzle 配置

在 `drizzle.config.ts` 中：

```typescript
import type { Config } from 'drizzle-kit';

export default {
  schema: './src/db/schema.ts',
  out: './drizzle',
  driver: 'pg',
  dbCredentials: {
    connectionString: process.env.DIRECT_URL, // 迁移时使用直连
  },
} satisfies Config;
```

## 🔐 安全注意事项

### ⚠️ 重要：保护数据库密码

1. **永远不要提交到 Git**
   - 确保 `.env` 文件在 `.gitignore` 中
   - 连接字符串包含数据库密码，是敏感信息

2. **使用环境变量**
   - 不要硬编码连接字符串
   - 生产环境使用环境变量或密钥管理服务

3. **密码管理**
   - 定期轮换数据库密码
   - 不要在代码、日志或文档中暴露密码

### 获取数据库密码

1. 登录 Supabase Dashboard
2. 进入 **Settings** > **Database**
3. 在 **Connection string** 部分查看或重置密码

## 🛠️ 使用场景

### 场景 1: 使用 Supabase Dashboard SQL Editor（当前方式）
- ✅ 不需要配置连接字符串
- ✅ 在 Dashboard 中直接执行 SQL
- ✅ 最简单的方式

### 场景 2: 使用数据库迁移工具（如 Prisma）
- 需要配置 `DATABASE_URL` 和 `DIRECT_URL`
- 使用 `DATABASE_URL` 用于应用连接
- 使用 `DIRECT_URL` 用于迁移

### 场景 3: 后端直接连接数据库（Node.js + pg）
- 需要配置 `DATABASE_URL`
- 安装 `pg` 包：`npm install pg`
- 使用连接字符串连接数据库

### 场景 4: 数据库管理工具（如 DBeaver、pgAdmin）
- 使用 `DIRECT_URL` 连接
- 可以查看和管理数据库结构

## 🔍 验证连接

### 测试连接字符串（命令行）

```bash
# 测试连接池连接
psql "postgresql://postgres.ebidxktbasohjqfqxxwh:[YOUR-PASSWORD]@aws-0-us-west-2.pooler.supabase.com:6543/postgres?pgbouncer=true"

# 测试直连连接
psql "postgresql://postgres.ebidxktbasohjqfqxxwh:[YOUR-PASSWORD]@aws-0-us-west-2.pooler.supabase.com:5432/postgres"
```

### 测试连接（Node.js 代码）

```typescript
import { Client } from 'pg';

// 测试连接池连接
const client = new Client({
  connectionString: process.env.DATABASE_URL
});

await client.connect();
console.log('✅ 连接成功');
await client.end();
```
